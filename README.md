# 패널로그 (Panelogue)

React, TypeScript, Zustand 기반의 AI 패널 토론 시뮬레이션 플랫폼입니다. 여러 AI 패널과 사회자가 주제별 토론을 진행하고 발언 근거, 입장 변화, 합의 과정을 기록합니다.

## 실행

```bash
npm install
npm run dev
```

품질 검사는 다음 명령으로 실행합니다.

```bash
npm run build
npm run lint
```

## 주요 기능

- 참가자별 페르소나, 모델 및 토론 성향 설정
- 동적·순차·사회자 중심 발언 진행
- 관객 질문과 진행자 명령
- 최근 대화, 중요 기억 및 팩트 원장을 이용한 프롬프트 구성
- 로컬 세션·에이전트 프리셋 저장과 결과 내보내기
- 최대 턴·토큰·예상 비용 제한

## 동작상 주의점

- `demo` 제공자는 실제 모델 호출 없이 로컬 예시 발언을 생성합니다.
- 실제 제공자 호출이 실패하면 토론이 일시정지되고 오류가 표시됩니다. 자동으로 데모 결과로 대체하지 않습니다.
- 표시되는 토큰과 비용은 응답 길이에 기반한 추정치이며 실제 청구 내역과 다를 수 있습니다.
- 브라우저 저장 공간이 제한되거나 차단된 환경에서는 세션 저장이 실패할 수 있습니다.
- 저장된 이전 버전 세션은 불러올 때 현재 기본 설정과 병합됩니다.

## 구조

- `src/engine`: 발언 순서, 상태 전환, 프롬프트 실행
- `src/services`: LLM 제공자 연동 및 출력 파싱
- `src/store`: Zustand 상태와 실행 제어
- `src/components`: 설정, 채팅, 요약 UI
- `src/utils`: 프롬프트, 프리셋, 저장 및 내보내기
